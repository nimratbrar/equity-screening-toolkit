# Examples

- `themes_security_resilience.json`: one example theme set (grid equipment, power cable, water, semiconductor
  materials and packaging, nuclear fuel cycle, critical minerals processing, digital security). Each theme
  lists segment-name and code rules, exclusions, core GICS codes, a short include list of public company names,
  description keywords and anchor customers. Use it as a template for your own themes with `theme_exposure.py`.
- `inputs_example.json`: illustrative inputs for a fictional company. Every number is made up.
- `monte_carlo_example.py`: a self-contained run of the valuation conventions on those inputs (needs only numpy).
